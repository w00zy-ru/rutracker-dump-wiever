# RuTracker Torrent DВ Viewer (Tauri)

Легковесная кроссплатформенная графическая утилита для просмотра, поиска и фильтрации раздач из локального дампа базы данных RuTracker.org.

Приложение спроектировано как простая читалка дампа базы **RuTracker.org**, собранного силами сообщества. Дамп базы и сопутствующее обсуждение оригинального приложения работы с ней, доступны в [официальной теме на RuTracker](https://rutracker.org/forum/viewtopic.php?t=4824458&start=2130).

Для работы данного приложения, трубуется основная база для оригинального приложения (infotor): torrents.db3.

## 📂 Использование и подготовка базы данных
* Импортировать базу данных [torrents.db3](https://rutracker.org/forum/viewtopic.php?t=4824458&start=2130), `Настройки ➔ Импорт базы DB3`.

## 🚀 Возможности
* **Каскадные фильтры**: Динамический выбор `Категория ➔ Форум` сужает область поиска.
* **Быстрые выборки**: Кнопки-пресеты для вывода свежих, крупных (>10 ГБ) или мелких раздач.
* **Интеграция с ОС**: 
  * Клик по названию раздачи открывает тему на форуме в системном браузере.
  * Кнопка **🧲 Magnet** отправляет ссылку напрямую в торрент-клиент.
  * Кнопка **📋 Магнет** копирует готовую магнет-ссылку в буфер обмена.
* **Компактность**: [Конечно, конечно...] Плюсом только единственный исполняемый файл.

## 🚀 Не реализовано
* Частичное обновление базы. Нет частичных обновлений оригинальной базы.
* Подробное описание раздач: в оригинале есть доп. БД с расширенным описанием, но в этом коде не реализовано за ненадобностью автору.

## Стек технологий
* **Tauri + Vanilla**  Нативный движок DuckDB быстро обрабатывает сотни тысяч строк.
* **Node.js**

## 🛠️ Сборка приложения

Для сборки проекта вам понадобятся установленные среды **Node.js** и **Rust** (компилятор `cargo`).

### 🐧 Сборка под Linux (на примере ALT Linux / Ubuntu)

1. Установите необходимые системные библиотеки разработки графического движка:
   ```bash
   # Для ALT Linux (через su -):
   apt-get install glib2-devel libgtk+3-devel libwebkit2gtk4.1-devel libssl-devel libayatana-appindicator3-devel librsvg-devel

   # Для Ubuntu / Debian:
   sudo apt install libgtk-3-dev libwebkit2gtk-4.1-dev build-essential libssl-dev libayatana-appindicator3-dev librsvg2-dev
   ```

2. Установите JS-зависимости проекта в корневом каталоге:
   ```bash
   npm install
   ```

3. Запустите компиляцию финального релиза:
   ```bash
   WEBKIT_DISABLE_DMABUF_RENDERER=1 npm run tauri build
   ```
   *Готовый переносимый пакет **`.AppImage`** и нативный бинарный файл будут лежать в папке `src-tauri/target/release/bundle/appimage/`.*

---

### 🪟 Сборка под Windows (не тестировалась)

1. Установите [C++ build tools](https://microsoft.com) через Visual Studio Installer (выберите рабочую нагрузку *«Разработка классических приложений на C++»*).
2. Убедитесь, что в системе установлен [WebView2 Runtime](https://microsoft.com) (в Windows 11 он встроен по умолчанию).
3. Откройте терминал (PowerShell / Сommand Prompt) в папке проекта и установите зависимости:
   ```powershell
   npm install
   ```
4. Запустите команду сборки:
   ```powershell
   npm run tauri build
   ```
   *Готовый автономный установщик **`.msi`** и исполняемый файл **`.exe`** будут находиться в директории `src-tauri\target\release\bundle\msi\`.*
